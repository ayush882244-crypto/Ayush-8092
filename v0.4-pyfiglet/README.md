# v0.4 pyfiglet

## what is pyfiglet

pyfiglet changes normal text into large ascii art banners

## install

```bash
python -m pip install pyfiglet
```

## first program

```python
import pyfiglet

banner = pyfiglet.figlet_format("AYUSH", font="slant")
print(banner)
```

## run

```bash
python v0.4-pyfiglet/first_banner.py
```

## experiment

change AYUSH to another word and run the program again

- how to install pyfiglet
