# v0.3 creative turtle learning log

## what i wanted to build

i wanted to draw a colourful geometric sea turtle on a dark background

## prompt used

help me combine pillow and turtle to make a simple colourful sea turtle and explain the code in beginner friendly words

## development steps

1. pillow creates the background image
2. turtle opens the background
3. turtle draws the flippers and shell
4. turtle adds the head eyes and tail

## something i learned

pillow can create an image and turtle can use that image as the screen background

## testing note

run the program on a computer with a graphical desktop and compare the drawing with the expected output
