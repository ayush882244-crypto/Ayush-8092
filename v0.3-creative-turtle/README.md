# v0.3 creative sea turtle

## what it does

this program combines pillow and turtle to draw a colourful sea turtle

## libraries

- pillow creates a dark background image
- turtle draws the shell head eyes flippers and tail

## install

```bash
python -m pip install Pillow
```

## run

from the repository folder run

```bash
python v0.3-creative-turtle/draw_turtle.py
```

## expected output

a turtle drawing with a colourful shell and four flippers on a dark background

## what i learned

- how to use pillow to create a background
- how to use turtle to draw shapes
- how two libraries can be used in one program

turtle needs a desktop graphics window so this file should be run locally rather than in a headless github actions runner
